# Apresentação de Vendas 2026 • BotConversa

Aplicação web interativa, responsiva (Mobile-First + Desktop) e otimizada para compartilhamento via WhatsApp da Apresentação de Vendas 2026 do BotConversa com narração neural em 1ª pessoa na voz do Tiago.

## 🚀 Funcionalidades
- **84 Slides em Alta Definição:** Frames Full HD (1920x1080) sincronizados com áudio neural nativo do Tiago.
- **Roteiro em 1ª Pessoa:** Transcrição completa com rolagem independente e reset automático a cada slide.
- **Player Responsivo:** Layout adaptável para smartphones e computadores, com controles de velocidade (1x, 1.25x, 1.5x, 2x) e tela cheia.
- **Conversão via WhatsApp:** Botão flutuante para retorno direto ao WhatsApp do parceiro com mensagem de fechamento pré-configurada.
- **Design System Oficial:** Identidade visual alinhada com a Central de Ajuda do BotConversa.

## 🛠️ Tecnologias
- HTML5 / CSS3 Moderno (CSS Grid + Flexbox)
- JavaScript Vanilla
- VoiceStudio Neural Voice Cloning (Tiago)
- Vercel Deployment
